# MingleClient
ShellShockers hack client with two-loop aimbot, predictive aiming, & bloom correction. Hold SHIFT (configurable) to aim. Press C to toggle rage (hardlocking) mode. Includes ESP (Digit 1) & Tracers (Digit 2).
